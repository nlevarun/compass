┌─────────────────────────────────────────────────────────────────────────┐
│                      TROUBLESHOOTING ERRORS                              │
└─────────────────────────────────────────────────────────────────────────┘

    ERROR: "no such column: feedback.external_ids"
    FIX: python fix_db.py
         └─> Deletes old DB, restart creates new schema

    ERROR: "Module not found"
    FIX: pip install --upgrade -r requirements-minimal.txt
         └─> Reinstalls all dependencies

    ERROR: "Database is locked"
    FIX: 1. Kill backend: lsof -ti:8000 | xargs kill -9
         2. Remove locks: rm -f compass.db-wal compass.db-shm
         3. Restart: python main.py

    ERROR: Validation fails
    FIX: python validate_system.py
         └─> Shows specific errors with fix suggestions
