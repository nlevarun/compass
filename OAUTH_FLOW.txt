    | 302 Redirect

│    - Workspace selector                                                 │
│    - Requested permissions list                                         │
│    - "Allow" / "Deny" buttons                                           │
│                                                                          │
│  User clicks "Allow"                                                    │
└─────────────────────────────────────────────────────────────────────────┘
    |
    | Slack redirects to callback URL with code + state
    |
    | HTTP GET /api/auth/slack/callback?code=xxx&state=yyy
    v
┌─────────────────────────────────────────────────────────────────────────┐
│  BACKEND - OAuth Callback Endpoint                                      │
│                                                                          │
│  slack_oauth.py:                                                        │
│    1. Verify state token (CSRF check)                                   │
│    2. Exchange code for access token:                                   │
│       - POST to slack.com/api/oauth.v2.access                           │
│       - Send: client_id, client_secret, code                            │
│       - Receive: access_token, team info, bot info                      │
│    3. Save to database:                                                 │
│       - Create Source record                                            │
│       - Store token in config JSON                                      │
│       - Mark as active                                                  │
│    4. Return HTML page with JavaScript:                                 │
│       - Sends postMessage to parent window                              │
│       - Closes popup after 2 seconds                                    │

SECURITY FEATURES
================================================================================

┌─────────────────────────────────────────────────────────────────────────┐
│  CSRF Protection                                                         │
│  ─────────────────────────────────────────────────────────────────────  │
│  State token:                                                           │
│    - Generated: secrets.token_urlsafe(32)                               │
│    - Stored: In-memory dict (oauth_states)                              │
│    - Validated: On callback                                             │
│    - Expired: After use (deleted from dict)                             │
└─────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────┐
│  Token Storage                                                           │
│  ─────────────────────────────────────────────────────────────────────  │
│  Access tokens:                                                         │
│    - Stored: Database config JSON field                                 │
│    - Never returned: In API responses                                   │
│    - Encrypted: Can add encryption at rest                              │
│    - Revoked: On disconnect via Slack API                               │
└─────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────┐
│  Scope Validation                                                        │
│  ─────────────────────────────────────────────────────────────────────  │
│  Requested scopes:                                                      │
│    - Minimal: Only what's needed                                        │
│    - Documented: In OAuth setup guide                                   │
│    - Audited: Stored with token                                         │
│    - Validated: By Slack during auth                                    │
└─────────────────────────────────────────────────────────────────────────┘
